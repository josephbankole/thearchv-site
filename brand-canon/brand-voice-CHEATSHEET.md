## Voice
Faceless "we", British English. **HUMANIZER PASS mandatory on all copy (D86):** run the humanizer skill's checklist + the "what's the AI tell? → fix it" audit before queueing. No AI vocab (delve/moreover/intricate/landscape/showcase/underscore/testament/pivotal/vibrant/boasts), no -ing tails, no copula-avoidance ("serves as"→"is"), no "not just X, it's Y", no forced rule-of-three, no em-dash spam, no hyphen-buzzwords (future-proofed/data-driven), no curly quotes. Write with a real take + varied rhythm. (Content agents may use first-person/"hot take" per their specs; the daily faceless voice does not.) Nostalgia/debate = neutral, all-clubs. **Transfer content = United lean (now a CORE pillar, ~40%).** LinkedIn = executive-editorial register (measured, framework-driven, ≤1 emoji). Never expose a person; never first-person-singular.

## Editorial standard — The Athletic (D-2026-07-23, football content)
All @thearchvfc football copy is written to **The Athletic's football-journalism standard**, adapted to short social. This is the ceiling for voice; the FPR/loop mechanics below still run underneath it, they do not override it.
- **Report, don't hype.** Lead with what is actually known, sourced and attributed by name (Ornstein, Romano, Sky). Rumour is labelled as rumour. No tabloid superlatives, no manufactured drama, no "BREAKING" theatre.
- **Earn the take.** Opinions are welcome but must rest on a specific fact, number, or moment, not vibes. Show the reasoning in a line, don't just assert.
- **Specific over generic.** Name the player, the fee, the date, the match, the minute. Concrete detail is the voice; filler adjectives are not.
- **Calm authority.** Measured, knowledgeable, a little dry. The reader should feel they are hearing from someone who actually watches the football, not a hype account.
- **Respect the reader.** No clickbait the post can't pay off, no hollow engagement bait, no cliché. A question is fine when it is a real question.
- **Accuracy is non-negotiable:** 2-source verify, never invent a stat, transfer status truthful and attributed. This sits on TOP of the existing hard rules, it never loosens them.
- The critic/banter unit stays banter, but banter written with this same restraint, never abuse.
- **Humanizer is still mandatory** (see Voice above): the Athletic standard is the target, the humanizer pass is how you strip the AI tells that would betray it. Do both, every unit.
- When a task dispatches to the copywriting/storytelling analyst, tell the analyst to edit to this standard by name.

## IMAGE GENERATION DOCTRINE (D90 — founder-ratified 2026-06-15, after the soul_2 incident)
Lesson: `soul_2` (Higgsfield Soul 2.0) silently runs a "prompt enhancer" that REWROTE a clean no-crest prompt and injected a Man Utd crest, an Umbro/Adidas logo, on-image text and a wrong-year trophy — direct D50 violations. The founder caught it. This doctrine exists so it never recurs.
1. **MODEL ALLOWLIST** for any ARCHV player/brand portrait or asset: **`nano_banana_2` (Nano Banana 2) is the default** — it renders the prompt verbatim, and it is what every prior legend (Evra/Okocha/Platini/etc.) used. `nano_banana_pro`, `nano_banana`, `seedream_v4_5` are acceptable only if they render verbatim. **BANNED for brand imagery: `soul_2` / `soul_v2` / `soul_cinematic` / `marketing_studio_image` / `ms_image` / `image_auto` — any model that auto-enhances or rewrites the prompt, or adds text.**
2. **EVERY prompt carries this negative line verbatim:** "No crest, no logo, no badge, no text anywhere." Plus national/club COLOURS only (D50). House frame: navy #0C2A3E, gold #C9A14A, cream #F2EAD3, film grain.
3. **ENHANCER TRIP-WIRE (mandatory):** after `generate_image`, read back `results[].params.prompt` and any `enhance_prompt` flag. If the returned prompt differs from what was sent, or `enhance_prompt` is true, **DISCARD the output and regenerate on an allowlisted model.** A rewritten prompt is an automatic reject, no exceptions.
4. **FOUNDER VISUAL QC before deploy:** no generated player image is wired into a post, queued, or banked until the founder has seen it (the sandbox cannot fetch the CDN image — 403 — so render it via `job_display` and get explicit sign-off). No silent deploys.
